Query Strings

Now that we can safely fetch and display data, you need a way to navigate between pages that use that data. That's where query strings come in.

It answers the question: "How do I pass the details of one record from one PHP page to another, and how do I handle large lists of results?"

Imagine you display images from a database in a gallery, and you loop through results and show thumbnails. Now when someone clicks a thumbnail, you want to go to a details page for that specific image. To tell the next page which image to show, you attach that image's ID to the link as a query string:

<a href="details.php?imgID=<?php echo $row['image_id']; ?>">View Details</a>

Clicking on the above code creates:

  1. the URL: 
    .../details.php?imgID=2
  2. a $_GET['imgID'] variable that the next page (details.php) can use. On details.php, validate and run a prepared SELECT using it.

Tips for Using Query Strings

To append multiple values to a URL, use & between each name=value pair.

If you're building a link yourself in PHP and the value is a string, encode it for proper handling. This is where the urlencode() function comes into play.

urlencode() safely encodes a string so it cane live inside a URL query string (after the ?), turning characters that could break the URL into percent-encoded sequences.

  • Space is encoded as: +
  • ? is encoded as: %3F
  • etc etc etc

Hidden Form Fields

Hidden form fields are another method for sending data to another page. 


<form action="img_details.php" method="post">
<input type="hidden" name="action" value="details">
<input type="hidden" name="imageID" value="<?= $row['imageID'] ?>">
<input type="submit" value="View Details">
</form>
