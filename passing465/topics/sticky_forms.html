Sticky Forms & Safer Output

A sticky form remembers what the user already typed and re-displays those values when there are validation errors. This makes the form friendlier because users don't have to re-enter correct data just because they made one mistake.

Sticky forms are usually built on top of a recursive form page: the same PHP file displays the form, validates input, redisplays errors, and (eventually) shows a confirmation.

Making Inputs Sticky

The basic idea: when you redisplay the form, you echo back the submitted values into the form controls if they exist and are valid.

  • Text inputs: use the value attribute.
  • Textarea: put the value between the opening and closing tags.
  • Radio buttons & checkboxes: conditionally add checked.
  • Select lists: conditionally add selected to the right option.
<!-- Text input sticky pattern -->
<input type="text" name="address"
       value="<?= htmlspecialchars($address ?? '') ?>">

<!-- Textarea sticky pattern -->
<textarea name="instructions"><?=
    htmlspecialchars($instructions ?? '')
?></textarea>

Example: Sticky Text Input with Error Message

We can combine the $missing array with sticky output to show a message and refill the input: 

<?php
$missing = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $address = trim($_POST['address'] ?? '');

    if ($address === '') {
        $missing['address'] = 'Address is required.';
    }

    if (empty($missing)) {
        echo '<h2>Thanks! Your pizza will be delivered to ' .
             htmlspecialchars($address) . '.</h2>';
        exit;
    }
}
?>

<h2>Pizza Order</h2>

<?php if (!empty($missing['address'])) : ?>
    <p class="warning"><?= $missing['address'] ?></p>
<?php endif; ?>

<p>
    <label for="address">Street Address:</label>
    <input type="text" name="address" id="address"
           value="<?= htmlspecialchars($address ?? '') ?>">
</p>

Sticky Radio Buttons & Select Lists

For radio buttons, you add checked when the submitted value matches: 

<!-- Sticky radio buttons for crust type -->
<label>
    <input type="radio" name="crust" value="hand"
        <?php if (isset($crust) && $crust === 'hand') echo ' checked'; ?>>
    Hand Tossed
</label>

<label>
    <input type="radio" name="crust" value="thin"
        <?php if (isset($crust) && $crust === 'thin') echo ' checked'; ?>>
    Thin Crust
</label>

For select lists, you add selected to the matching option: 

<label for="cheese">Cheese Amount:</label>
<select name="cheese" id="cheese">
    <option value="normal"
        <?php if (isset($cheese) && $cheese === 'normal') echo ' selected'; ?>>
        Normal Cheese
    </option>
    <option value="extra"
        <?php if (isset($cheese) && $cheese === 'extra') echo ' selected'; ?>>
        Extra Cheese
    </option>
</select>

Note: keep a space before selected or checked, or your rendered HTML will look like value="extra"selected, which is invalid.

Sticky Checkboxes with Arrays

When you use name="toppings[]", PHP collects the checked values into an array (for example, $toppings). You can use in_array() to keep each box checked. 

<!-- Assume $toppings is an array from $_POST['toppings'] -->
<label>
    <input type="checkbox" name="toppings[]" value="pepperoni"
        <?php if (isset($toppings) && in_array('pepperoni', $toppings)) echo ' checked'; ?>>
    Pepperoni
</label><br>

<label>
    <input type="checkbox" name="toppings[]" value="mushrooms"
        <?php if (isset($toppings) && in_array('mushrooms', $toppings)) echo ' checked'; ?>>
    Mushrooms
</label><br>

<label>
    <input type="checkbox" name="toppings[]" value="olives"
        <?php if (isset($toppings) && in_array('olives', $toppings)) echo ' checked'; ?>>
    Olives
</label>

Why Sticky Forms Need Cross-Site Scripting (XSS) Protection

When you redisplay user input in a sticky form, you're echoing exactly what the user typed back into the browser. If they type HTML or JavaScript, it can break your page or become a cross-site scripting (XSS) attack.

To defend against this, always escape user data on output using functions like:

  • htmlspecialchars() - converts &, ', ", <, and > into their safe HTML entities.
  • htmlentities() - converts all applicable characters into HTML entities (more aggressive).
  • strip_tags() - removes all HTML and PHP tags from a string.
<?php
// Dangerous if $instructions contains <script>...</script>
echo "Special instructions: " . $instructions . "<br>";

// Safer:
echo "Special instructions: " .
     htmlspecialchars($instructions) . "<br>";

With htmlspecialchars(), something like: <script>alert('Gotcha!');</script> is rendered as harmless text instead of executable JavaScript.

Sticky Forms Checklist

When you build a sticky form, you should:

  • Use a recursive page.
  • Collect errors and missing fields in arrays like $missing or $errors.
  • Redisplay the form if there are problems, with:
    • Clear error messages near the relevant inputs.
    • Sticky values in value, textarea, checked, and selected.
  • Escape all user data with htmlspecialchars() before echoing it back.
