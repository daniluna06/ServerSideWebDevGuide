Form Processing

Form processing is the heart of "dynamic" PHP pages. A user fills out an HTML form, the browser sends the data to the server, and your PHP script validates, cleans, and uses that data (for example: saving to a database, sending an email, or showing a confirmation message).

Request Methods & Superglobals

Forms send data using either GET or POST. PHP receives that data in superglobal arrays:

  • $_GET - data from the URL query string (for example: ?name=Jim).
  • $_POST - data from the HTTP request body (most common for forms).
  • $_REQUEST - combo of GET, POST, and COOKIE.
  • $_SERVER - info about the request, including $_SERVER['REQUEST_METHOD'] ("GET" or "POST").

POST is preferred for form submissions because it can handle larger amounts of data and is more secure (data isn't visible in the URL). Use GET for simple searches or when bookmarking results is useful.

Basic Flow of Form Processing

The typical pattern for a processing script:

  1. Check if the form was submitted.
  2. Pull values out of $_POST (or $_GET).
  3. Validate and sanitize the data:
    • Make sure required fields aren't empty.
    • Check types and formats (email, numbers, etc.).
    • Make sure values are acceptable (not negative, within range, etc.).
  4. If there are errors, redisplay the form with messages (and sticky values (more on this later)).
  5. If everything is good, process the data (insert into the database, send email, show success page, etc.).
<?php
$errors = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // 1. Get the values
    $name  = trim($_POST['name'] ?? '');
    $email = trim($_POST['email'] ?? '');

    // 2. Validate
    if ($name === '') {
        $errors['name'] = 'Please enter your name.';
    }

    if (empty($email)) {
        $errors['email'] = 'Please enter an email address.';
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors['email'] = 'Please enter a valid email address.';
    }

    // 3. Process if no errors
    if (!$errors) {
        // process the data (for example, save to DB)
    }
}
?>

HTML Form Example

Here's a simple registration-style form that sends data to process_form.php using POST: 

<form action="process_form.php" method="post">
    <fieldset>
        <legend>Register:</legend>

        <p>
            <label for="name">Name:</label>
            <input type="text" name="name" id="name">
        </p>

        <p>
            <label for="email">Email:</label>
            <input type="text" name="email" id="email">
        </p>

        <p>
            <label for="age">Age:</label>
            <input type="text" name="age" id="age">
        </p>

        <p>
            <input type="submit" name="submit" value="Register">
        </p>
    </fieldset>
</form>

Notice how each control has a name. Those names become the keys in $_POST or $_GET (for example: $_POST['email']).

Processing the Form & Basic Validation

This is a simple process_form.php that checks for submission, validates input, and shows a success message or errors: 

<?php
$errors = [];

if (isset($_POST['submit']) && $_POST['submit'] === 'Register') {

    // Trim input
    $name  = trim($_POST['name'] ?? '');
    $email = trim($_POST['email'] ?? '');
    $age   = trim($_POST['age'] ?? '');

    // Required text fields
    if ($name === '') {
        $errors['name'] = 'Name is required.';
    }

    if (empty($email)) {
        $errors['email'] = 'Email is required.';
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors['email'] = 'Please enter a valid email address.';
    }

    // Numeric check
    if ($age === '') {
        $errors['age'] = 'Age is required.';
    } elseif (!is_numeric($age)) {
        $errors['age'] = 'Age must be a number.';
    } elseif ($age < 0) {
        $errors['age'] = 'Age cannot be negative.';
    }

    if (!$errors) {
        echo '<h2>Thanks, ' . htmlspecialchars($name) . '!</h2>';
        echo '<p>We have registered <strong>' .
             htmlspecialchars($email) . '</strong>.</p>';
        exit;
    }
}
?>

Helper Functions for Form Validation

Some very common PHP helpers for form processing:

  • empty($var) - TRUE if the variable is not set or is "empty" ("", 0, null, etc.).
  • isset($var) - TRUE if the variable exists and is not null (useful for radios, checkboxes, and submit buttons).
  • is_numeric($var) - TRUE if the value is a number or a numeric string (can be safely converted).
  • filter_var($email, FILTER_VALIDATE_EMAIL) - validates email format.

Typical pattern for a text box: 

if (empty($_POST['address'])) {
    $errors['address'] = 'Address is required.';
} else {
    $address = trim($_POST['address']);
}

And for non-text (like a submit button or checkbox): 

if (!isset($_POST['terms'])) {
    $errors['terms'] = 'You must accept the terms.';
}

Arrays in Forms & foreach Processing

Some form controls send arrays, especially multi-select lists and multiple checkboxes with the same name.

Example checkbox group for favorite toppings:

<label>
    <input type="checkbox" name="toppings[]" value="mushrooms"> Mushrooms
</label>
<label>
    <input type="checkbox" name="toppings[]" value="olives"> Olives
</label>
<label>
    <input type="checkbox" name="toppings[]" value="onions"> Onions
</label>

On submit, PHP receives $_POST['toppings'] as an array, so you loop with foreach: 

if (!empty($_POST['toppings']) && is_array($_POST['toppings'])) {
    foreach ($_POST['toppings'] as $topping) {
        echo htmlspecialchars($topping) . '<br>';
    }
}
