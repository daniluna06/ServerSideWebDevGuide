Cookies and Sessions

HTTP is stateless, meaning it doesn't remember any information between pages. When you go from one html page to another, the pages themselves are separate entities. So if I log in on one page, the next page I'm directed to doesn't remember that I'm logged in. If you click from the "home" page to "shop," the website doesn't automatically know it's you. Your browser remembers what you've seen, but the website's server doesn't. That's a problem if the site needs to remember things- like what's in your shopping cart, or that you already logged in. That's where PHP comes in to save the day. PHP can keep track of you using two tools:

  • 🍪 Cookies → little pieces of info stored on your computer.
  • 💻 Sessions → info stored on the server that follows you while you browse.

Together, they help the website "remember" things — so your cart, login, or preferences actually stick around instead of disappearing every time you click something.

Cookies Sessions
Store data in the user's browser Store data on the server
Name/value pairs sent by a server to store information on the client's machine Data generated by the server and stored on the server
When you set or delete a cookie in PHP, it doesn't instantly show up in the same page where you did it. The cookie only becomes active the next time the browser loads a new page- or reloads the current one. When you use sessions in PHP, the data you save in a session is available right away, even on the same page, without needing to reload or go anywhere else.
  1. PHP sends a cookie to your browser: "Set cookie: user = Daniela"
  2. Browser receives it but doesn't give it back yet. Cookie is saved locally on your computer.
  3. You reload or go to another page. Browser: "Hey server, here's that cookie you gave me earlier!"
  4. Server now knows who you are (user = Daniela).
  1. PHP starts a session for you: session_start()
  2. PHP gives you a special session ID (like a ticket number).
  3. You set a session variable: $_SESSION["user"] = "Daniela";
  4. It's instantly saved on the server. You can use $_SESSION["user"] right away- no reload needed.
