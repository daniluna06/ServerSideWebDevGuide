PHP Intro

PHP is a server-side scripting language that works together with HTML, CSS, and JavaScript to create dynamic web pages.

The Client-Server Model & HTTP

When you type a URL and hit Enter, your browser (the client) sends an HTTP request to a web server. The server processes the request and sends back an HTTP response that includes:

  • Response headers - information about the server and the data being sent.
  • Response body - the actual content the browser renders (usually HTML, CSS, JS).

HTTP stands for Hypertext Transfer Protocol. Request headers carry information about the client (like browser type), and response headers describe the server's answer.

Static vs. Dynamic Websites

  • Static pages - plain HTML/CSS/JS. The same content is sent to every user.
  • Dynamic pages - use a server-side language (like PHP) to change the content based on data, input, or user state.

Browsers interpret client-side code (HTML, CSS, JavaScript). This code is visible in the page source and is not secure by itself.

With server-side code (like PHP), the web server executes the script, talks to a database if needed, and only sends the final HTML back. The actual PHP code does not appear in the page source, which is one of the reasons it's used for more secure logic.

Web Servers & Software Stacks

A web server is just a computer that responds to HTTP requests.

Your site runs on an application "stack" that usually includes:

  • Operating system
  • Web server software
  • Database
  • Server-side scripting language

Common stacks:

  • LAMP: Linux, Apache, MySQL, PHP (our stack in CSC465).
  • WISA: Windows, IIS, SQL Server, ASP.NET.
  • MERN: MongoDB, Express.js, React, Node.js.
  • MEAN: MongoDB, Express.js, Angular, Node.js.

Basic PHP Syntax

  • PHP is HTML-embedded - you mix PHP code inside an HTML file.
  • The file must use the .php extension, not .html.
  • PHP code goes inside <?php ... ?> tags.
  • Statements end with a ;.

Variables & Data Types

In PHP:

  • Variables start with $ (for example, $firstName).
  • Variable names are case-sensitive.
  • No type declarations: PHP figures out the type at runtime.
  • Names can use letters, numbers, and underscores, but can't start with a digit or use reserved names (like $this).

Common PHP data types include:

  • integer
  • double
  • boolean
  • string
  • array
  • object

Comments in PHP

Three ways to write comments:

  • // single-line comment
  • # single-line comment (shell style)
  • /* ... */ multi-line comment

Strings, Quotes, & Interpolation

  • Strings must start and end with the same type of quote.
  • Single quotes treat the contents literally.
  • Double quotes allow interpolation - variables inside the string are replaced with their values.
<?php
$first_name = 'Jimmy';
$last_name  = 'Halpert';

// Literal (no interpolation)
$name1 = '$first_name $last_name'; // outputs: $first_name $last_name

// Interpolated
$name2 = "Name: $first_name $last_name"; // outputs: Name: Jimmy Halpert
?>

You can also mix quotes or use the backslash \ to "escape" a quote character inside a string: 

$last_name = "O'Brien";
$line      = 'She said, "Hi."';

$last_name = 'O\'Brien';
$line      = 'She said, \'Hi.\'';

Echo, Print, Concatenation, & Escape Sequences

Echo and print both send output to the browser. You'll mainly use echo.

To glue strings together, PHP uses the concatenation operator .: 

<?php
$city  = 'Wilmington';
$state = 'NC';

$locale = $city . ', ' . $state; // Outputs: Wilmington, NC
echo "Welcome to " . $locale . "!"; // Outputs: Welcome to Wilmington, NC!
?>

Some characters have special meanings in PHP strings and must be escaped with \:

  • \" double quote
  • \' single quote
  • \\ backslash
  • \n newline
  • \t tab
  • \$ literal dollar sign
