Recursive Forms

A recursive form is a single PHP page that both displays the form and processes it. Instead of having one page for the HTML and a second page for the processing, everything happens in one script using conditionals.

This pattern makes it easier to validate input, redisplay the form with error messages, and eventually make the form "sticky" so users don't have to retype everything when they make a mistake.

Two-Page Procedure vs. One Recursive Page

Traditional approach (two pages):

  • Page 1: Displays the HTML form.
  • Page 2: Processes the submitted data and shows a confirmation or errors.

Recursive approach (one page):

  • The same script decides whether to show the form or process the data.
  • PHP checks "Was the form submitted?" and branches accordingly.
<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // Form was submitted: validate and process
} else {
    // First visit (or direct hit): just display the form
}
?>

This is called "recursive" because the page calls itself: the form's action points back to the same script.

Basic Structure of a Recursive Form Page

The "skeleton" for a recursive page usually looks like this: 

<?php
$errors  = [];
$missing = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // 1. Validate input
    // 2. Add missing/invalid fields to $missing or $errors

    if (empty($missing) && empty($errors)) {
        // 3. Process data
        // 4. Output confirmation
        // 5. Exit so the form is NOT redisplayed
        exit;
    }
}
// If we get here, either it's the first load OR there were errors.
// Show the form (possibly with error messages and sticky values).
?>

When the form is submitted and passes validation, the script runs the "success" block and uses exit; to stop the rest of the page from rendering.

Tracking Missing & Invalid Input

A common pattern is to use one or more associative arrays (like $missing or $errors) to track problems with the form fields: 

<?php
$missing = [];
$errors  = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {

    // Example: required text field
    $address = trim($_POST['address'] ?? '');
    if ($address === '') {
        $missing['address'] = 'Address is required.';
    }

    // Example: numeric field
    $age = $_POST['age'] ?? '';
    if ($age === '' || !is_numeric($age)) {
        $errors['age'] = 'Please enter a valid numeric age.';
    }

    if (empty($missing) && empty($errors)) {
        // Process the valid data and exit
        echo '<h2>Thank you! Your information was submitted.</h2>';
        exit;
    }
}
?>

After processing, you check whether $missing or $errors has anything in it. If they're empty, you finish and exit. If not, you fall through and display the form again with messages.

Example: Simple Recursive Contact Form

<?php
$missing = [];
$errors  = [];

// Process if submitted
if ($_SERVER['REQUEST_METHOD'] === 'POST') {

    // Name: required text
    $name = trim($_POST['name'] ?? '');
    if ($name === '') {
        $missing['name'] = 'Name is required.';
    }

    // Email: required text
    $email = trim($_POST['email'] ?? '');
    if ($email === '') {
        $missing['email'] = 'Email is required.';
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors['email'] = 'Please enter a valid email address.';
    }

    // Message: optional, but we could still trim/inspect it
    $message = trim($_POST['message'] ?? '');

    if (empty($missing) && empty($errors)) {
        // Normally: send email or insert into database
        echo '<h2>Thanks, ' . htmlspecialchars($name) .
             '! Your message has been received.</h2>';
        exit;
    }
}
?>

<h2>Contact Us</h2>

<?php if (!empty($missing) || !empty($errors)) : ?>
    <p class="warning">Please fix the item(s) indicated below.</p>
<?php endif; ?>

<form action="recursive_contact.php" method="post">
    <p>
        <label for="name">Name:</label>
        <input type="text" name="name" id="name"
               value="<?= htmlspecialchars($name ?? '') ?>">
        <?php if (!empty($missing['name'])) echo '<span class="warning">' .
                 $missing['name'] . '</span>'; ?>
    </p>

    <p>
        <label for="email">Email:</label>
        <input type="text" name="email" id="email"
               value="<?= htmlspecialchars($email ?? '') ?>">
        <?php
        if (!empty($missing['email'])) {
            echo '<span class="warning">' . $missing['email'] . '</span>';
        } elseif (!empty($errors['email'])) {
            echo '<span class="warning">' . $errors['email'] . '</span>';
        }
        ?>
    </p>

    <p>
        <label for="message">Message:</label>
        <textarea name="message" id="message"><?=
            htmlspecialchars($message ?? '')
        ?></textarea>
    </p>

    <p>
        <input type="submit" value="Send">
    </p>
</form>

Notice that the top PHP block does all the processing and decides whether to show the confirmation (and exit) or fall through to redisplay the form with messages and sticky values.

exit() and the Footer

One important detail: once you call exit;, the rest of the page will not render. If your header and footer are in external files, you need to think about where you include them.

  • If you want the confirmation page to show the footer, output the footer before you call exit;.
  • If there are multiple "successful paths" (like pizza examples), you might have to include the footer in more than one place so both paths end with valid HTML.
