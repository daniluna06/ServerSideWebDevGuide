APIs

An Application Programming Interface (API) is a set of rules or protocols that let two applications talk to each other. Instead of writing every feature from scratch, one program can call another program's API to request data or trigger functionality.

In web development, APIs are often used to:

  • Get data from other systems (weather, maps, payments, etc.).
  • Reuse complex services (like payment processing) without reinventing the wheel.
  • Connect your PHP site to outside services and data sources.

Types of Web APIs

Common categories of web APIs you'll see in the wild:

  • Open APIs - publicly available, often with a free tier, but usually still require an API key.
  • Partner APIs - require a license or partnership and special rights to access.
  • Private APIs - internal to a company; used by their own systems only.
  • Composite APIs - combine multiple data/service APIs to speed up execution with a single request.

API styles you'll encounter:

  • SOAP (Simple Object Access Protocol)
    • Uses XML for request/response.
    • More rigid and verbose, more complicated to parse.
  • REST (Representational State Transfer)
    • Uses standard HTTP methods: GET, POST, PUT, PATCH, DELETE for CRUD operations.
    • Typically returns JSON (JavaScript Object Notation).
    • What you used with WeatherAPI.com.

JSON: The Language of REST APIs

JSON (JavaScript Object Notation) is the standard way REST APIs send data over the web. It's:

  • Easy for humans to read and write.
  • Easy for machines to parse and generate.
  • Used to transmit data between a server and a web application (as an alternative to XML).

Basic JSON building blocks

  1. Objects
    • Enclosed in { }.
    • Made of key/value pairs.
    • Keys are strings, values can be strings, numbers, objects, arrays, booleans, or null.
  2. Arrays
    • Enclosed in [ ].
    • Can contain multiple values of any type (including objects).
  3. Values
    • Strings, numbers, objects, arrays, booleans, or null.

Example JSON

{
  "name": "John Doe",
  "age": 30,
  "isStudent": false,
  "courses": ["Math", "Science", "History"],
  "address": {
    "street": "123 Main St",
    "city": "Anytown",
    "zipCode": "12345"
  }
}

When an API responds with JSON like this, PHP can decode it and let you access values like name, courses, and address->city.

Using an API: General Steps

Most web APIs, including WeatherAPI.com, follow the same general workflow:

  1. Register on the API website and create an account.
  2. Get an API key - a unique token that identifies your application.
  3. Read the documentation to learn:
    • What endpoint URLs you can call.
    • Which query string parameters are required (e.g., location, units, format).
    • How the response JSON is structured.
  4. Construct the request URL with query strings, including your API key.
    • Example pattern:
      http://api.weatherapi.com/v1/current.json?key=YOUR_KEY&q=Tokyo
  5. Send the request from your PHP script and get the JSON response.
  6. Decode the JSON, pull out the values you care about, and display them on your page.

Retrieving API Data with PHP

PHP gives you two key functions for working with REST APIs that return JSON:

  • file_get_contents() - reads the contents of a URL or file into a string.
  • json_decode() - converts a JSON-encoded string into a PHP value (object or array).

Basic pattern

// 1. Build the URL (with query string + API key)
$apiUrl = "http://api.weatherapi.com/v1/current.json?key=YOUR_KEY&q=Tokyo";

// 2. Call the API and get the raw JSON response
$response = file_get_contents($apiUrl);

// 3. Decode the JSON into a PHP object
$data = json_decode($response);

// 4. Access fields using -> because $data is an object
$city      = $data->location->name;
$tempf     = $data->current->temp_f;
$condition = $data->current->condition->text;

Dot notation from JSON (like location.name) becomes arrow notation in PHP (->location->name), because decoded objects may have names that don’t fit normal PHP variable rules (like hyphens).

Weather API Lab: Japan Weather Page

For a page that shows live weather for cities in Japan using WeatherAPI.com, the PHP file:

  • Reads a city from the query string (defaulting to Tokyo).
  • Builds a WeatherAPI current.json URL using that city and your API key.
  • Uses file_get_contents() and json_decode() to get the live data.
  • Displays temperature, feels-like, condition text, humidity, and an icon.
  • Includes a select list so the user can pick another Japanese city.

Key parts of the lab code

<?php
include 'includes/header.php';

// 1. Get city from query string (default: Tokyo)
if (isset($_GET['city'])) {
    $selectedCity = $_GET['city'];
} else {
    $selectedCity = 'Tokyo';
}

// 2. Local date/time for Japan
date_default_timezone_set('Asia/Tokyo');
$currentTime = time();
$localDate   = date("jS F, Y", $currentTime);
$localTime   = date("l h:i A", $currentTime);

// 3. Build the WeatherAPI URL
$apiUrl = "http://api.weatherapi.com/v1/current.json?key=YOUR_KEY&q=$selectedCity";

// 4. Call the API and decode JSON
$response      = file_get_contents($apiUrl);
$data          = json_decode($response);
$city          = $data->location->name;
$tempf         = $data->current->temp_f;
$humidity      = $data->current->humidity;
$feelslikef    = $data->current->feelslike_f;
$condition     = $data->current->condition->text;
$conditionIcon = $data->current->condition->icon;
?>

Then in the HTML portion, output the values:

<h2><?php echo $city; ?> Weather Status</h2>
<h3>Local Date: <?php echo $localDate; ?></h3>
<h3>Local Time: <?php echo $localTime; ?></h3>

<h2>Current Conditions</h2>
<h3>Temperature: <?php echo $tempf; ?> &deg;F</h3>
<h3>Feels Like: <?php echo $feelslikef; ?> &deg;F</h3>
<h3>Condition: <?php echo $condition; ?></h3>
<img src="<?php echo $conditionIcon; ?>" alt="Weather Icon">
<h3>Humidity: <?php echo $humidity; ?>%</h3>

And a simple form lets the user choose a different city via the query string:

<form action="weather.php" method="get">
    <label for="city"></label>
    <select name="city" id="city">
        <option value="" selected>Find weather in another city in Japan:</option>
        <option value="Kyoto">Kyoto</option>
        <option value="Osaka">Osaka</option>
        <option value="Yokohama">Yokohama</option>
        <option value="Sapporo">Sapporo</option>
        <option value="Tokyo">Tokyo</option>
    </select>
    <input type="submit" value="Go">
</form>

This combines everything: query strings, API calls, JSON, and PHP output into one dynamic API-powered page.

Date & Time Formatting for APIs

Many APIs include date and time information, or you may want to display the local time for a location (like you did for Tokyo).

  • Use date_default_timezone_set() to match the location.
  • Use date() with formatting codes to display readable dates and times.
  • The full list of PHP date/time format codes is available in the PHP manual.

Example from your lab:

date_default_timezone_set('Asia/Tokyo');
$currentTime = time();
$localDate   = date("jS F, Y", $currentTime);   // e.g., 27th November, 2025
$localTime   = date("l h:i A", $currentTime);   // e.g., Thursday 03:15 PM
