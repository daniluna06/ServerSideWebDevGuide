External Files

As your site grows, it becomes a pain to update the same header, navigation, or footer on every single page. External files let you cut common pieces into separate files and pop them into each page with PHP, so one change updates the whole site.

Breaking a Page into Reusable Pieces

A typical site page can be split into three main parts:

  • Everything at the top of the page that is the same on all pages of the site. This usually includes the DOCTYPE, the head section and the opening HTML elements
  • The part of the page that is unique to the page.
  • The bottom of the page that is the same on every page, usually the footer and closing HTML elements.

With external files, you move the shared top into something like header.php and the shared bottom into footer.php. Each content page then just requires those files and focuses on its unique content.

include(), require(), and Their _once Versions

PHP gives you functions to pull in external files:

  • include('file.php'); - if the file can't be found, PHP shows a warning but keeps running.
  • require('file.php'); - if the file can't be found, PHP shows an error and stops the script.
  • include_once() / require_once() - same behavior, but only load the file once, even if the statement is hit multiple times (useful for functions/classes).

Common patterns for this class:

  • header: usually uses require() because the page isn't very useful without the header and nav.
  • footer: often uses include() because the page can still function without it.
  • If the file defines functions or classes, it's safer to use require_once().

How PHP Treats Included Files

When you call include() or require(), PHP behaves as if it:

  1. Finds the external file.
  2. Copies all its code.
  3. Pastes that code right where the include / require statement appears.

File Structure & Simple Example

An example index.php might look like:

<?php
require 'includes/header.php';
?>

<main>
    <h2>Welcome to Seahawk Pizza</h2>
    <p>Best slices in Wilmington.</p>
</main>

<?php
include 'includes/footer.php';
?>

The index file itself contains very little HTML, but once the header and footer are pulled in, the final output is a complete HTML document.

External Nav File & Current Page Highlight

The navigation menu can also live in its own external file, which makes it easy to update links and dynamically highlight the current page using $_SERVER.

Example includes/nav.php:

<?php
$current = basename($_SERVER['SCRIPT_NAME']);
?>
<nav>
    <ul>
        <li><a href="index.php"
               <?php if ($current === 'index.php') echo 'id="current"'; ?>>Home</a></li>
        <li><a href="menu.php"
               <?php if ($current === 'menu.php') echo 'id="current"'; ?>>Menu</a></li>
        <li><a href="about.php"
               <?php if ($current === 'about.php') echo 'id="current"'; ?>>About Us</a></li>
    </ul>
</nav>

Now the nav is centralized, and the id="current" styling updates automatically based on which page is being viewed.
